# Сценарий user-test — Ближе 0.1.0

Цель: проверить естественность продукта. **Не объясняйте механику заранее.**

## Перед тестом

1. Отправьте тестеру файл `blizhe-0.1.0-hypothesis.apk` (или debug APK).
2. Не говорите про «фейкового партнёра», IndexedDB, PWA, симуляцию.
3. Скажите только: «Это тестовая версия приложения для пар. Установи и попробуй около 5–10 минут.»

## Установка (Android)

1. Открыть APK с телефона.
2. Если система предупредит об установке из неизвестного источника — разрешить установку **только для этого файла / этого источника** (стандартный системный диалог).
3. Не просите отключать глобальную безопасность устройства.

## Сценарий (без подсказок)

1. Установить приложение.
2. Пройти onboarding (имена).
3. Ответить на вопрос дня.
4. Дождаться ответа «партнёра» (обычно 10–20 секунд).
5. Посмотреть reveal обоих ответов.
6. Поставить реакцию.
7. Завершить день и посмотреть сад.
8. Открыть историю.
9. Открыть Couple Plus и нажать CTA.
10. Закрыть приложение полностью.
11. Открыть снова — данные должны остаться.

## Вопросы после сессии

- Что было непонятно?
- Что понравилось?
- Что было лишним?
- Хотелось ли бы открыть это завтра?
- Позвали бы вы партнёра?
- За что здесь потенциально готовы платить?

Самый важный сигнал:  
> «Я бы реально попробовал(а) это со своим партнёром».

## Для фасилитатора (не показывать тестеру)

- Test Lab: Settings → 7 taps по версии.
- Сброс: Settings → Сбросить демо-данные.
- Экспорт событий: Test Lab → Экспортировать тестовые данные.
