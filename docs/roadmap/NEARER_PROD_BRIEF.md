## Суть
Приложение для пары: ежедневный ритуал + 3-недельные «растения» в саду отношений + архив списков/моментов.  
Данные local-first, синк **E2E** (сервер не читает дневник).

## Куда расти (prod)
Не выбирать между daily и садом — связать три петли: **pulse (сегодня) → period (растение) → archive (наше/моменты)**.  
Сад = коллекционная эмоциональная ценность; Plus = все растения, полная память, PDF, сезоны.

## Фазы
0. Recovery ключ, фото в списках, push, аналитика  
1. Garden v2: периоды, 8–12 растений, история цветка  
2. Архив ↔ сад, polish, onboarding второго  
3. Монетизация Couple Plus (web/RevenueCat)  
4. Stores, FCM, Memory Book, контент-редактор  

## Монетизация
Free: связь, daily, 3–4 растения, базовый архив.  
Plus: весь сад, история, PDF, фото/сезоны. Не monetize E2E и базовый reveal.

## Для инвестора
Метрики пары (не скачиваний): linked retention, bloom rate, trial→paid.  
Moat: privacy + эмоциональный артефакт (сад), не «ещё один чат».
